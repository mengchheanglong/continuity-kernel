# Non-Claims

The foundation benchmark does **not** claim:

- consciousness, subjective continuity, mind transfer, immortality, or personhood;
- that a scoped computational identifier identifies or proves a natural person;
- that stored memory or behavioral similarity constitutes identity;
- that a successful synthetic erasure vector proves GDPR compliance;
- that SHA-256 provides authenticity or tamper evidence against an attacker who can rewrite state and recompute the digest;
- that DBOS workflow history is canonical domain history or a privacy-safe audit ledger;
- that a DBOS workflow ID proves equality of two requests;
- exactly-once behavior for arbitrary filesystem, network, logging, messaging, or second-database effects;
- gapless PostgreSQL sequences;
- production availability, scalability, security, latency, or recovery SLOs;
- external demand, product-market fit, or organizational viability;
- that one DBOS-specific failure establishes a need for custom persistence;
- that an event-sourced architecture is required.

## Approved description

> A research-grade conformance harness for testing continuity properties across stateful agent and simulation runtimes.

Any stronger public description requires new evidence and Mission Control approval.
